## 字段

每条资源含 9 列：名称 · 官网 · 许可 · 免费商用(✅/⚠️/❌) · 署名 · 需注册 · 地区 · 特色 · GitHub。

## 使用与贡献

- 选资源先看「免费商用」与「署名」两列，商用前以原站许可页为准。
- 新增资源请阅读 [CONTRIBUTING.md](CONTRIBUTING.md)，保持中英双语同步；改完文档运行 `python3 tools/build_data.py` 重建数据源。
- 标注 ⚠️ 待核实的条目，使用前请人工复核授权与可用性。
