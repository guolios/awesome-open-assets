> **Selection Guide**
> - **For prototype demos, pick Kenney without hesitation**: all CC0, large volume and not ugly—the default starting point for indie games
> - **For specific character/scene styles** → OpenGameArt or itch.io, but⚠️ use license filters then confirm each asset's actual terms
> - **For pixel-art palettes** → Lospec has a complete palette list for color reference
> - **Front-end devs need placeholder images** → Lorem Picsum (real photos, customizable size/grayscale/blur); Placehold.co (solid color + custom text)
> - ⚠️ **Liberated Pixel Cup is CC BY-SA**; derivatives must be released under the same terms—evaluate SA's copyleft before using in a closed-source commercial game
