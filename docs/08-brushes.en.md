# 08 · Brushes (Brushes)

> Free drawing brushes for Procreate / Photoshop / Clip Studio to enrich hand-drawn texture quickly.
> Brush licenses are trickier than images: many are 'free for personal, license for commercial' — always check each brush's terms.
