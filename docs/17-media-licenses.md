# 17 · 多媒体授权速查与常见坑（Media License Basics）

> 视频、音频、字体、动效各自有自己的坑。这一篇与 [10 · 授权速查](10-licenses.md) 配合使用：
> **10 讲通用条款（CC / MIT / OFL 等），17 讲多媒体领域特有的雷区。**
> 一句话概括：图片踩的是「授权类型」的坑，音视频踩的是「权利分层」的坑，字体踩的是「软件 vs 字形」的坑。

---

## 17.1 音频篇

**① 三层权利互相独立**
一段流行音乐同时存在：**词曲著作权**（音乐作品）、**录音制作者权**（母带）、**表演者权**（演唱/演奏）。拿到其中一层 ≠ 全部拿到。
典型陷阱：公版歌词配新录音、公版乐谱配非公版录音，都是「半公版」。

**② "免版税 Royalty-Free" ≠ 免费，≠ 无限制**
RF 只是「不必按次付版税」，多数仍需一次性付费或订阅，且常排除广播、院线上映、游戏内嵌等场景。

**③ YouTube Audio Library 的三条细则**
- 部分曲目明确要求把署名文本贴进视频简介，且**每条署名文本只对一部视频有效**
- 授权本质依附于 YouTube 平台条款，平台条款变更或曲目下线（很常见）会直接影响你既往项目的证据链
- 不能被单独再分发，不能被拿去宣称 Content ID

**④ NCS（NoCopyrightSounds）并非公有领域**
它是受著作权保护的音乐，只是作者对创作者免费开放使用；NCS 明确禁止把曲目打包成素材库，并要求逐曲核对条款。
同理，网页上写的「免费 / 无版权即可商用」几乎都不成立，务必回源头看条款原文。

**⑤ AI 生成音乐/音效**
多数平台的免费档不授予商用权；即使付费档也可能保留「不得作为素材包出售」「不得用于二次训练」的限制。更要命的是——**纯 AI 音频通常不受著作权保护**，意味着你也很难阻止别人原样使用。

**⑥ Sample/采样授权绑定「最终用途」**
不能打包成 sample pack 转售、不能做成音效 App 或素材站。
多个音效站（ZapSplat、SampleFocus、Coverr）已明文写入「**禁止用于训练或评测任何 AI/ML 模型**」——做数据集/训练时必须逐站核对。

**⑦ CC BY-NC 是重灾区**
Freesound、ccMixter、FMA 都混有大量 NC 曲目。「挂广告的 YouTube 视频算不算商用」业界普遍倾向算，风险由使用者承担。**搜索时务必用 License 过滤器（CC0/CC BY），不要看默认结果。**

## 17.2 视频篇

**⑧ 机构档案是「逐条授权」而非「整站授权」**
British Pathé、AP Archive 的教育/预览授权与商用授权是两码事；Library of Congress 与 Internet Archive 上大量条目标注为「版权状态未知」。下载前看单条 Rights Statement，不要看站点口号。

**⑨ "政府作品 = 公有领域"只在特定法域成立**
美国联邦政府作品在美国属于 PD，但 NASA/NOAA 素材中可能夹杂第三方拍摄或受肖像权约束的镜头；英国 Crown Copyright、欧盟多国政府作品通常需按开放政府许可署名。跨国投放不能套用同一结论。

**⑩ 肖像权、商标权、物权不因 CC0 而豁免**
Pexels、Pixabay、Coverr、ISO Republic 都明确写了「不保证模特授权书 / 不保证商标与私有物产授权」。出现可辨识人脸、品牌 Logo、私有雕塑或地标建筑时，商业项目要另行取得授权。

**⑪ 研究数据集的默认用途就是「研究」**
ESC-50、UrbanSound8K（NC-SA）、MTG Jamendo（音轨为 CC，商用需另谈）、AudioSet（本体为 YouTube ID，受 YouTube 条款约束）都不适合直接喂给商业产品。
**「用数据集训练 → 训练好的模型商业化」往往已超出授权范围。**

**⑫ 不要用素材去做素材站的竞品**
Pexels、Pixabay、Coverr、Vecteezy、ZapSplat 全部禁止把下载的素材（哪怕经过轻微剪辑）用于构建素材库、模板站、App 打包出售。**这是被起诉概率最高的一条。**

## 17.3 字体篇

**⑬ SIL OFL 的边界：可嵌入、可改、可分发，但不可单独售卖字体文件**

OFL 允许：免费商用（印刷、网页、App、Logo、嵌入销售的产品）、修改与子集化、随产品分发、无需署名。

OFL **不允许**的三件事，恰恰最容易被误踩：

| 禁止项 | 具体含义 |
| --- | --- |
| 不得单独出售字体文件 | 把 `Inter.woff2` 打包成「字体素材包」卖钱，或做成以字体为核心的付费 App，都违反 OFL。**允许卖「用了该字体的作品」，禁止卖「字体这个文件」** |
| RFN（保留字体名） | 修改并再分发时必须用**不同的名字**（不能还叫 Roboto），且衍生版本必须继续沿用 OFL |
| 不得删除内嵌声明 | 字体文件内的版权声明与许可文本不可移除 |

**⑭ 字体授权 ≠ 字形著作权，各国认定差异极大**

| 法域 | 认定倾向 |
| --- | --- |
| 中国 | 司法实践倾向认定具独创性的单字/字库属美术作品，**已有企业因包装上使用他人字体中的数个字被判侵权**。中文字体在中国是风险最高的资产类别 |
| 美国 | 字库**软件**受著作权保护，但纯字形设计通常不被认定为可版权作品，故多以「软件许可」方式授权 |
| 欧洲部分国家 | 对字体设计有专门或更宽松/更严格的规则 |

> 结论：**跨境项目按最严格的司法辖区（通常是中国或品牌方所在国）做合规。**

**⑮ 中文字体「免费商用」声明的举证义务**
站酷、阿里巴巴普惠体、MiSans、OPPO Sans、HarmonyOS Sans、钉钉进步体、抖音美好体**都不是开源协议**，而是厂商单方授权声明 —— **声明可以被修改或撤销**。

商用前必须做的三件事：**① 从官方渠道下载；② 截图存档官方声明页（含 URL 与日期）；③ 留存下载来源。**

各家附加条件不同，务必逐条读：

| 字体 | 关键限制 |
| --- | --- |
| 站酷系列 | 禁止改名、禁止转售牟利、禁止把字体文件二次交付给客户（属「品牌公益授权」，比 OFL 严格得多） |
| 阿里巴巴普惠体 3.0 | 禁止反编译、禁止删除法律声明、禁止单独定价出售/出租/转授权、禁止发布误导性合作背书信息 |
| MiSans | 要求在软件中特别注明使用了 MiSans；禁止改编/二次开发，禁止单独对外分发字体软件 |
| OPPO Sans | 不得改编或二次开发，不得对外售卖 |

> ⚠️ **商标注册场景是各家声明的高危区**，多个厂商对「将字体用于商标/Logo 注册」态度不一致，注册前必须单独确认。

**⑯ 品牌字体与系统自带字体不可随意商用**

- **微软雅黑**：版权属方正，Windows 授权只覆盖「在 Windows 上显示」，网页 `@font-face` 嵌入或再做商业发布需另行授权
- **苹方 / San Francisco**：Apple 授权仅限 Apple 平台开发使用
- **方正、汉仪、造字工房**等的商业字体：绝大多数需付费授权，网上流传的「免费下载」几乎都是盗版

> **一句话原则：「电脑上自带」不等于「可商用」，「能下载到」不等于「有授权」。**

**⑰ 嵌入与分发的技术红线**
- 用 `@font-face` 自托管字体属于**分发行为**。OFL 允许，但要求随附许可与版权声明（实践中把 LICENSE 放在字体目录或站点致谢页）
- 子集化（subset）属于修改，OFL 允许，但要保留版权声明并遵守 RFN 规则
- 通过 Google Fonts CDN 加载会向 Google 发送访客 IP，属**隐私合规（GDPR）问题**而非授权问题，欧盟项目常改自托管

## 17.4 动效与生成器篇

**⑱ GIF / 表情包含大量第三方 IP**
Giphy、Tenor 上的 GIF 绝大多数截取自影视剧、综艺、动漫、体育赛事或明星素材，平台条款只解决「平台内分发」，**完全不解决上游版权与肖像权**。
表情包同理：Noto Emoji 的**字形**是 OFL 开源的，但各平台（Apple / 微信 / 抖音）的表情**形象**是各自的作品，不能直接搬用。

**⑲ Lottie 免费 ≠ 免费商用，且免费档普遍需署名**
Lordicon 免费档可商用但**必须署名**，且禁止打包分发、禁止做成以图标为核心的产品；Icons8、Loading.io 同理需署名；IconScout / LottieFiles 是混合库，必须逐条看作者标注。
Lottie 文件中常包含第三方插画、品牌 logo 或动漫形象，**这些绝不可商用**。
> 运行时层面（lottie-web / ThorVG / rlottie）是 MIT 或自有开源许可，使用无碍；有风险的是**素材本身**。

**⑳ 生成器产出物：可商用，但普遍禁止转售与搭竞品**
Haikei、Fffuel、BGJar、Blobmaker、Get Waves、Shape Divider 条款结构高度一致：产出物可商用（BGJar 免费档需按 CC BY 4.0 署名），但**禁止把产出物打包成素材包/模板转售，禁止用它搭建同类竞品服务**。
另外：生成器产出的 SVG 多为算法随机结果，**同款撞车率高**，不适合作为品牌唯一视觉识别。

## 17.5 通用（三条最高优先级）

1. **下载时务必保留证据** —— 无论授权多干净，自动化 Content ID 都可能误判。保存下载时间、来源 URL、当时的 License 截图与作者名，发生下架争议时这是唯一自证材料。
2. **yt-dlp 的法律边界** —— 工具本身开源合法，但下载受版权保护内容、规避技术保护措施在多数法域违法或违反平台条款，注意各国「技术规避条款」差异。
3. **条款是会变的** —— Pixabay 2019 年从 CC0 改为自有授权，Reshot 被 Envato 关停，站酷/阿里等厂商声明可修改。**重要项目请保留下载当天的许可页面快照。**

## 17.6 一页纸决策流程

```
拿到一段音频 / 视频 / 一支字体
  ├─ 音频：是否三层权利都拿到了（词曲 + 录音 + 表演）？
  │      └─ 只拿到一层 → 视为不可用
  ├─ 视频：片中有无可辨识人脸 / 品牌 logo / 私有地标？
  │      └─ 有 → 另需肖像授权，且避免暗示代言
  ├─ 字体：是 SIL OFL / Apache 开源字体，还是厂商单方声明？
  │      ├─ OFL → 可商用可改可分发，但不得单独售字体文件、改名须换名
  │      └─ 厂商声明 → 存档声明页 + 遵守其附加条件（禁改名/禁二次分发/须注明）
  ├─ 数据集：授权是否含 NC / -SA / 仅限研究？
  │      └─ 有 → 商业模型训练已超范围
  └─ 通用：是否会用素材去搭建素材库/模板站竞品？
         └─ 会 → 几乎所有平台都明文禁止，风险最高
```
