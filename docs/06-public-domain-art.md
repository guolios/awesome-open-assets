# 06 · 公共领域艺术 / 复古插画（Public Domain Art）

> 博物馆、图书馆与档案馆开放的**公共领域 / CC0 艺术与复古插画**，是做海报、封面、文创、历史感设计的金矿。
> 多数为 CC0 或公有领域，**可商用且无需署名**；个别站点需看单条权利声明。

> 想找**最干净授权** → 认准 CC0：Met Museum、Rijksmuseum、Smithsonian、Paris Musées、Art Institute of Chicago。
> **Wikimedia Commons / Europeana** 是聚合站，条目授权混合，下载前点开单条看 License。
> 商业大批量使用名画时，注意部分博物馆对「衍生品」有额外条款。
