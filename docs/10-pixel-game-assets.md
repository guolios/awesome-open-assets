> **选型建议**
> - **做原型 Demo，闭眼选 Kenney**：全站 CC0，量大且不丑，是独立游戏圈的默认起点
> - **找特定风格的角色/场景** → OpenGameArt 或 itch.io，但⚠️两者都用 license 筛选后再确认单件素材的实际条款
> - **做像素画的调色盘** → Lospec 有完整的 palette 列表，可作色彩参考
> - **前端开发要占位图** → Lorem Picsum（真照片，支持指定尺寸/灰度/模糊）；Placehold.co（纯色块 + 自定义文字）
> - ⚠️ **Liberated Pixel Cup 是 CC BY-SA**，衍生作品须以相同条款开放，用于商业闭源游戏前需评估 SA 的传染性
