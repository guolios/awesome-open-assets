# 02 · 公共领域与机构典藏（Public Domain & Cultural Heritage）

> 博物馆、图书馆、航天机构开放的馆藏扫描件，**多为 CC0 或公有领域，是授权最干净的一档素材**。
> 适合做书籍封面、文化类设计、历史考据、壁纸，以及任何你想彻底规避版权风险的商用场景。

> **选型建议**
> - 做**书籍封面 / 文创衍生品**：优先 The Met、Rijksmuseum、Smithsonian — 名画本身早已进入公有领域，扫描件又 CC0，双保险
> - 做**科技感 / 航天题材**：NASA Image Library 全部公有领域，连宇航员肖像都可商用
> - ⚠️ **混合授权平台一定逐件看**：Wikimedia Commons、Europeana、DPLA 里同一站的不同条目授权可能完全不同；NYPL 有大量仍在版权期的近代照片
