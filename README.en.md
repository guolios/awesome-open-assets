# Awesome Open Assets · Open-Source Asset Index

> 🌏 A curated index of openly-licensed, free-for-commercial assets for creators & developers — globally sourced.
> Every entry is tagged with its **license, commercial usability, and attribution requirement**, so you can use it without stepping on copyright landmines.

**Scope**: **392 sites / projects** (categories 01–17) + 2 license cheat-sheets ｜ **Updated**: 2026-10 ｜ **Status**: actively maintained

Covers **images · video · audio · fonts · motion · 3D · game art · colors · tooling** — nine domains.

## Why the name

This repo is meant to be a **long-lived asset ledger**, so the name intentionally leaves room to grow:

| Dimension | Design rationale |
| --- | --- |
| `assets` not `images` | Future-proof: can smoothly expand to fonts, audio, video, palettes, design-system files — no rename or migration needed |
| `open` not `free` | Emphasizes **explicitly commercial-friendly licensing**, not just "stuff that costs nothing" |
| `awesome-` prefix | The de-facto convention for discovery-style lists in the GitHub ecosystem |

> One-liner: **An Awesome List for creative assets — Chinese-first in presentation, but the resources are global.**

> ✅ This naming has already paid off once: the repo started with images only (150 entries); video, audio, fonts, motion, palettes, and tooling all later merged into the same taxonomy and field schema.
> **The repo name, Description, and directory structure never changed a single character** — that's exactly why we avoided `awesome-free-images`.

## Table field reference (shared by all category files)

| Field | Values | Meaning |
| --- | --- | --- |
| **License** | CC0 / MIT / Apache-2.0 / custom … | The license that applies. Mixed platforms are marked "mixed" |
| **Commercial use** | ✅ yes / ⚠️ partial / ❌ no | "partial" = only specific collections, free tier, or with restrictions |
| **Attribution** | not required / required / varies | Whether you must credit the source in your work |
| **Signup** | no / yes / partial | Whether downloading requires an account |
| **Region** | US / EU / CN / Global … | Primary language or maintainer location |
| **GitHub** | link or `—` | Repo URL if the asset itself is an open-source project |

> ⚠️ **"partial" does not mean "use it freely".** With ⚠️, click through to see exactly which part is free and what you must do to comply.
> Entries marked **待核实 / to-verify** mean the license or availability could not be 100% confirmed during research — re-check manually before using.

## Usage tips

1. **Lock the scenario before picking a site** — for consumer-facing ads go to Unsplash / Pexels; for derivative works use only CC0 / museum collections.
2. **Keep proof when you download** — screenshot the license page on the day of download. Pixabay switched from CC0 to a custom license in 2019; terms do change.
3. **Avoid people and trademarks** — recognizable persons in ads need a separate model release; logos inside assets are not covered by the CC license.
4. **Be cautious with AI-generated content** — most stock sites now mix in AI-generated assets, which may not be copyrightable in many jurisdictions.
5. **Audio has three layers of rights** — a track carries songwriting, sound recording, and performer rights simultaneously; holding one ≠ holding all.
6. **Check whether a font is OFL or a vendor statement** — SIL OFL lets you embed, modify, and redistribute, but you may not sell the font file alone; ZCOOL / Alibaba / MiSans are one-sided vendor statements you must archive and whose extra conditions you must honor.
7. **Datasets are research-only by default** — datasets with NC / -SA (ESC-50, UrbanSound8K, …) exceed their scope if used to train commercial models.
8. **Never build a competing asset site from the assets** — this is an explicit ban across all platforms and the single highest-litigation-risk move.

## Contributing

New open / free-for-commercial asset sites are welcome. Please read [CONTRIBUTING.md](CONTRIBUTING.md) first and keep the table format consistent:

```
| Name | URL | License | Commercial | Attribution | Signup | Region | One-line note | GitHub |
```

Inclusion criteria:

- ✅ Must be a **real, reachable** site or open-source repo (open it to confirm before submitting)
- ✅ License terms are **explicit**, and at least part of it is free for commercial use
- ✅ When in doubt, leave it out — no padding the list
- ❌ Remove sites that are dead, paywalled, or unclear, and explain why in the PR

> Broken links? Feel free to open an Issue.
